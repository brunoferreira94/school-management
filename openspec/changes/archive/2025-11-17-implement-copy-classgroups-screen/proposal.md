# Implementar Tela para Cópia de Turmas

Autor: _a definir_
Data: 2025-10-18
Status: draft

Resumo

Tela para duplicar turmas (classgroups), útil para criar turmas semelhantes entre anos letivos ou turnos.

Motivação

- Reduzir trabalho repetitivo na criação de turmas com mesmas características.

Escopo

- Frontend: seleção de turma origem, opções de duplicação (horário, professores, vagas).
- Backend: endpoint de duplicação e validações.

Critérios de aceitação

- Turmas duplicadas preservam dados essenciais e geram novos identificadores.

Próximos passos
