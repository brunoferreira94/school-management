# Implementar Tela para Cópia de Cursos

Autor: _a definir_
Data: 2025-10-18
Status: draft

Resumo

Tela que permite duplicar cursos existentes (com e sem turmas) para acelerar criação de variações e novos cursos.

Motivação

- Reaproveitar estrutura de cursos e reduzir trabalho manual em configuração.

Escopo

- Frontend: UI para selecionar curso origem, opções de duplicação (conteúdo, avaliações, cargas horárias).
- Backend: endpoint para duplicação com opções e validações.

Critérios de aceitação

- Cursos duplicados mantêm relações essenciais (disciplinas, carga horária) e permitem edição posterior.

Próximos passos

- Detalhar campos copiados e conflitos em `design.md`.

Documentação pós-implementação
